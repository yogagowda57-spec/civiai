## 📌 Overview

**CiviAI** is an AI-powered citizen assistance platform that simplifies access to government services, schemes, and grievance support.

Instead of navigating multiple government websites, users can interact with an intelligent AI assistant that understands natural language, recommends relevant government schemes, guides users through eligibility, and redirects them to official government portals.

The goal is to make government services **simple, accessible, and intelligent** for every citizen.

# 🎯 Problem Statement

Citizens often struggle to:

* Find the right government schemes
* Understand eligibility
* Navigate multiple government websites
* Know required documents
* Identify the correct department for grievances

CiviAI solves these challenges using AI-driven guidance and intelligent service discovery.

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/CiviAI.git
```

Go to the project directory

```bash
cd CiviAI
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm start
```
